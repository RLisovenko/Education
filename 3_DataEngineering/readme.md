## Topics

- Python and SQL for data engineering
- Relational databases and PostgreSQL
- Data extraction, transformation, and loading (ETL/ELT)
- Data validation, cleaning, and pipeline reliability
- Distributed data processing with PySpark
- SQL transformations and analytical models with dbt
- Workflow orchestration with Airflow
- Lakehouse foundations and object storage
- Streaming pipelines with Kafka and Spark *(planned)*

## Organization

Course materials are organized in separate folders for datasets, documentation, notebooks, outputs, and PowerShell, Python, and SQL scripts. Container configuration and other supporting files are added when needed by a practical exercise.
