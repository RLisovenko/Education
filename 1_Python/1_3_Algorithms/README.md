# 🟢 Simple Python Programs

This branch contains **simple Python programming exercises** and small algorithmic challenges.  
Each project focuses on basic Python skills, problem-solving, and fundamental algorithms.

---

## 📂 Project List

1. **9. Palindrome Number** — check if a number reads the same backward and forward.  
2. **7. Reverse Integer** — reverse the digits of an integer.  
3. **869. Reordered Power of 2** — determine if digits of a number can be reordered to form a power of two.  
4. **383. Ransom Note** — check if a ransom note can be constructed from a magazine string.  
5. **168. Excel Sheet Column Title** — convert a number to its corresponding Excel column title.  
6. **326. Power of Three** — determine if a number is a power of three.  
7. **13. Roman to Integer** — convert Roman numerals to an integer.  
8. **3. Longest Substring Without Repeating Characters** — find the length of the longest substring without repeating characters.  
9. **20. Valid Parentheses** — check if a string of parentheses is valid.  
10. **434. Number of Segments in a String** — count the number of segments in a string.  
11. **125. Valid Palindrome** — check if a string is a palindrome, ignoring non-alphanumeric characters.  
12. **136. Single Number** — find the number that appears only once in a list.  
13. **169. Majority Element** — find the element that appears more than ⌊n/2⌋ times in a list.  
14. **202. Happy Number** — determine if a number is a happy number.  
15. **205. Isomorphic String** — check if two strings are isomorphic.

Each project contains **Python code** and can be run independently.
